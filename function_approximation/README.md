# Function approximation

This folder contains the reproducible source audits and FEX-derived surrogates reported in `TAIS.tex`.

The Fortran source defines

```text
savedtke1 = cwat * kme(level 1)
```

with `cwat = 4.188e6`. The current manuscript lake relation fits the constrained
Eq. 7 source form directly in `savedtke1`; the fitted constants and its held-out
metrics are saved by `fex_savedtke1_source_form.py`. The methane relation is a
separate one-variable quadratic in level-1 saturated methane concentration.

Run from the repository root:

```text
python function_approximation/lake_density_pathway.py
python function_approximation/make_lake_density_table.py
```

Outputs from the source audit:

- `lake_density_savedtke1_equations.txt`: source equations, symbolic checks, branch audit, and finite-expression screening.
- `lake_density_savedtke1_table.csv`: source-audit records selected from the lake grids.
- `lake_density_savedtke1_table.tex`: LaTeX rows inserted into the lake table.

## Original-FEX-grammar regression

`fex_original_regression.py` ports the supplied `Finite-expression-method-main`
`depth2` tree to paired E3SM records. It preserves the archive's operator
grammar (`0`, `1`, `x`, `x^2`, `x^3`, `x^4`, `exp`, `sin`, `cos`, with `+`,
`*`, and `-`) and replaces only the PDE residual with supervised mean-squared
error. The output states this adaptation explicitly; it is not a claim that
the archive's PDE entry point was run on CSV data.

Run:

```text
python function_approximation/fex_original_regression.py
```

The script writes `fex_original_lake_methane_equations.txt` and
`fex_original_lake_methane_metadata.json`, plus ten-row held-out tables
(`fex_original_lake_pathway_table.*`, `fex_original_lake_savedtke1_table.*`,
and `fex_original_methane_concentration_table.*`). The
one-input lake fit is retained as a diagnostic and has essentially zero
held-out R2, showing that `savedtke1` alone is not an adequate density
predictor. The publication candidate is the full lake pathway FEX equation
(`lake_pathway`), whose standardized inputs are reported in the text file.
The methane equation is the one-input concentration FEX fit.

All reported scores are a fixed random screening split. Independent E3SM
period/site validation remains a separate workflow and must not be implied by
these screening statistics.

## Restricted compact equations

`fex_simple_regression.py` generates one-line, polynomial FEX-compatible
diagnostics using a restricted grammar and complexity selection. These are
useful for readability experiments, but they are not automatic replacements
for the publication equations: the compact lake fit gives random-holdout
`R2=0.9882` and chronological `R2=0.8968`, while the compact methane
quartic gives random-holdout `R2=0.9827` but chronological `R2=-9.44`.
The original-FEX equations remain available as high-capacity comparison
baselines. The manuscript's current readable equations are the constrained
savedtke-only lake form and the compact methane quadratic described below.

## Constrained one-variable source form

`fex_savedtke1_source_form.py` locks the Eq. 7 source structure and fits only
the scalar coefficients \(\alpha\), \(\beta\), and \(\gamma\), with

```text
R(S) = sqrt((beta/(S-gamma)-1)/37)
rho_w(S) = alpha/(R(S)*(10*R(S)+1)),  S = savedtke_1.
```

Run it with:

```text
python function_approximation/fex_savedtke1_source_form.py
```

The fitted constants and one-line LaTeX expression are saved in
`fex_savedtke1_source_form.txt`; JSON metadata and twenty held-out rows are saved
alongside it. This is a calibrated one-variable source-form expression. Its
held-out score must be reported with the equation because fixed coefficients do
not remove the context dependence of the other pathway states.

`methane_simple_fex.py` searches short one-variable methane expressions and
selects the simplest robust candidate using both random and chronological
holdouts. The current selected equation is a quadratic in normalized methane
concentration; its random and chronological held-out (R^2) values are 0.8135
and 0.9448, respectively. The full original-FEX expression remains available
when maximum random-split accuracy is more important than readability.

## Methane-temperature surrogate

`methane_temperature_pathway.py` remains a diagnostic audit of the legacy Eq. 9 candidates. The legacy form explains the reviewer's 5.9 and 13.0 values: those are degrees Celsius, not Kelvin. The manuscript uses the compact quadratic generated by `methane_simple_fex.py`; the legacy logarithmic and exponential forms are retained only for review traceability.
